□ □ □ 加入名单

1. 叉子这种还本付息
2. 将您的 GitHub 手柄添加到 [`followers.md`] (跟随器. md):
   ```markdown

   ```
3. 打开公关——机器人自动出现

** 跟着名单上的每一个人——他们跟着你。 ** 这是整个合同。 新成员加入名单的底部并努力通过.
